## Statement from the report

> **AI usage disclosure:** Portions of this report text were supported by AI-based
> language models for improving clarity and formatting. All system architecture

## What this means for this repository

- **AI assistance was used for report text only** — clarity and formatting — not
  for the system itself.
- **All architecture, perception logic and ROS 2 code is the authors' own.** This
  covers the AprilTag pose recovery, the ring-band colour mask, the hue
  classifier, the fusion windows and the MoveIt 2 manipulation sequence.
- **Nothing in this repository was generated by AI.** The preparation pass that
  produced this repository — packaging, documentation, the architecture diagrams,
  the dependency corrections — is described in `docs/CHANGES.md`. It changed no
  algorithm and no parameter default.

Note on the README: the READMEs, architecture diagrams and this document were
written by the repository maintainer during preparation. The disclosure above is
preserved unchanged because it describes the *original* project, which is what
this repository presents.
